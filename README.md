# Social Content Management Dashboard

A React + TypeScript MVP dashboard for the social content management system described in the PRD. It includes a navigation shell, master composer, per-platform content variants, AI caption assistant, publishing status, calendar, and engagement inbox.

## Included features

- Sea blue and cream design system matching the PRD palette
- Left sidebar and desktop-first dashboard layout
- Master content composer with platform tabs
- AI caption assist panel with sample prompts and options
- Publishing, calendar, and comment inbox mock views
- Responsive layout for tablet/mobile widths

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Notes

This is the MVP front-end shell for product validation. It uses realistic mock data and is ready for backend/API integration in later phases.
